ARSITEKTUR

Metode lama dibanding pendekatan Banklycs.

Perbandingan ini menjelaskan bentuk penyimpanan dan alur rundown, bukan angka performa yang belum diukur.

METODE LAMA

Loose Filesystem Storage

  • Banyak berkas: Ribuan berkas teks dan presentasi tersebar dalam direktori.
  • Salinan lambat: Menyalin banyak berkas kecil bergantung pada kecepatan storage dan jumlah metadata.
  • Indeks library penuh: Semua lagu berisiko masuk ke library ProPresenter.
  • Ketergantungan runtime: Alur lama membutuhkan Python dan driver database terpisah.
METODE BANKLYCS

Single-File SQLite dan On-Demand

  • Satu berkas: Seluruh katalog berada di database SQLite tunggal.
  • Transfer praktis: Satu berkas lebih mudah disalin dan diverifikasi checksum-nya.
  • Rundown terarah: Hanya lagu yang dipilih operator yang masuk alur ProPresenter.
  • Aplikasi mandiri: Installer desktop memakai .NET self-contained tanpa instalasi Python.

PANDUAN OPERATOR

Tiga langkah memakai Banklycs.

Alur desktop dan simulator browser dibedakan dengan jelas.

1

Pasang Banklycs

Unduh Banklycs-Setup-2.7.0.exe, jalankan installer, lalu buka Banklycs dari shortcut Desktop atau Start Menu.

2

Pilih lagu dan susun rundown

Cari judul, artis, atau nomor buku. Pilih lagu lalu tambahkan ke rundown ibadah.

3

Jalankan alur ProPresenter

Di aplikasi desktop, pakai tombol inject Banklycs untuk menyiapkan rundown di ProPresenter. Tombol simulasi di portal hanya menunjukkan alur dan tidak menulis berkas.

PERTANYAAN UMUM

Pertanyaan yang sering muncul.

Jawaban teknis seputar penggunaan Banklycs di lingkungan ibadah.

Tidak. Katalog dan alur utama bekerja dari berkas lokal di komputer operator.

Tidak. Aplikasi desktop memakai .NET self-contained beserta engine dan SQLite di dalam satu proses.

Alur desktop menulis lagu rundown ke folder Banks di direktori dokumen ProPresenter dan mendaftarkan playlist yang sesuai.

Banklycs menyimpan nama berkas sebagai identitas tambahan, sehingga lagu berjudul sama dari buku atau artis berbeda tetap dapat dibedakan.

Simulator tetap bekerja untuk sesi tersebut. Portal menampilkan pemberitahuan bahwa rundown tidak disimpan lokal.
