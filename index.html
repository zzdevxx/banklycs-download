ARSITEKTUR & PERFORMA

Perbandingan Metode Lama vs Banklycs

Mengapa arsitektur single-file SQLite dan on-demand Protobuf jauh lebih stabil untuk komputer ibadah gereja.

METODE LAMA (PULUHAN RIBU FILE)

Loose Filesystem Storage

  • Overload Filesystem: Menyimpan 40.000 file terpisah (20.000 .txt dan 20.000 .pro) memakan lebih dari 300 MB dan memperlambat Windows Explorer.
  • Transfer Flashdisk Lambat: Menyalin 40.000 file ke flashdisk USB butuh 10 sampai 15 menit akibat metadata file FAT32/NTFS.
  • ProPresenter Lambat & Rentan Crash: Memuat puluhan ribu lagu di Library menyebabkan indeks Lucene bentrok dan startup lambat bermenit-menit.
  • Ketergantungan Eksternal: Membutuhkan runtime Python dan driver database yang sering tidak terpasang di laptop gereja.
METODE BANKLYCS (TERVERIFIKASI)

Single-File SQLite & On-Demand

  • Single-File Database: Seluruh 24.520 lagu tersimpan dalam 1 file database SQLite tunggal berukuran 61.42 MB, rapi dan bebas disk bloat.
  • Transfer USB Instan: Memindahkan file database hanya butuh 1 sampai 2 detik karena hanya 1 berkas kompak.
  • ProPresenter Selalu Ringan: Startup ProPresenter di bawah 1 detik karena hanya menampung 5 sampai 10 lagu rundown aktif di folder Banks.
  • Nol Dependensi (Zero Setup): Menggunakan engine native C# .NET 8 self-contained dengan SQLite tertanam tanpa butuh instalasi Python.

PANDUAN OPERATOR

Cara Penggunaan 3 Langkah Cepat

Alur kerja yang dirancang agar relawan non-teknis hingga lansia dapat menyajikan lirik ibadah dengan mudah.

1

Jalankan START.vbs

Double-click file START.vbs di folder aplikasi. Server engine C# berjalan secara senyap di background (100% tanpa jendela terminal hitam CMD) dan jendela aplikasi terbuka di layar.

2

Pilih Lagu & Susun Rundown

Ketik judul lagu, lirik, atau nomor buku pada kotak pencarian. Klik tombol + TAMBAH pada lagu yang dipilih untuk memasukkannya ke dalam daftar rundown ibadah minggu ini.

3

Klik INJECT TO PRO7

Klik tombol biru INJECT TO PRO7. Engine mengompilasi Protobuf secara realtime ke folder ProPresenter. Buka ProPresenter 7, dan playlist ibadah langsung siap tayang seketika.

PERTANYAAN UMUM

Frequently Asked Questions

Jawaban atas pertanyaan teknis seputar penggunaan Banklycs di lingkungan ibadah.

Banklycs sama sekali tidak memerlukan instalasi Python pada komputer operator. Engine utama telah dikompilasi menggunakan C# .NET 8 native ke dalam satu file binary mandiri (banklycs.exe) dengan SQLite bawaan di dalamnya.

Lagu-lagu yang dipilih operator dikompilasi dan disimpan langsung ke dalam folder Library khusus bernama Libraries/Banks/ di direktori dokumen ProPresenter Anda, dan playlist didaftarkan ke Playlists/Library.

Engine Banklycs menggunakan pencarian eksak berbasis nama file (filename). Jika ada dua lagu berjudul sama yang dinyanyikan artis berbeda atau nomor buku berbeda, sistem tetap mengambil lirik yang tepat dan tidak akan tertukar.
